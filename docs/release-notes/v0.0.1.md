# Intune Package Builder 0.0.1 (Vorabversion)

Erste veröffentlichte Fassung: ein Windows-Programm, das aus einer MSI, einer EXE oder einem Herstellerordner ein Microsoft-Intune-Win32-Paket (`.intunewin`), ein eigenständiges Erkennungsskript und eine Intune-Anleitung erzeugt.

**Das ist eine Vorabversion.** Sie ist durch automatisierte Prüfungen auf Windows-Runnern abgesichert, aber nicht auf Geräten erprobt.

## Inhalt der ZIP

Portables Verzeichnis: `IntunePackageBuilder.exe` starten, keine Installation, keine Administratorrechte nötig. Dabei liegen Bedienungsanleitung (`docs/BEDIENUNG.md`), bekannte Grenzen, Prüfprotokoll, Lizenz und Drittanbieterliste. Prüfsummen aller Dateien stehen in `SHA256SUMS.txt`.

**Download prüfen:** `Get-FileHash IntunePackageBuilder-0.0.1.zip -Algorithm SHA256` und mit der Datei `.sha256` neben der ZIP vergleichen.

## Voraussetzungen

- Windows 11 oder Windows Server 2019 und neuer mit Desktop Experience (Server 2019: .NET Framework 4.8 nachinstallieren).
- Das Win32 Content Prep Tool (`IntuneWinAppUtil.exe`) gehört **nicht** zum Lieferumfang (Lizenz); das Programm führt Sie beim ersten Bau dorthin.

## Was nicht erledigt ist

- **Nicht signiert.** Windows kann beim Start warnen.
- **Keine Geräte- und Bedienungstests** (Spec §12.2): kein Test mit realen Paketen im SYSTEM-Kontext, keine Prüfung auf Windows Server 2019, keine Prüfung von Skalierung, Tastaturbedienung und Aussehen. Alle Tests stehen als offen in `docs/PRUEFPROTOKOLL.md`.
- Es gibt kein Fortschrittsfenster auf dem Zielgerät, und die Benutzertexte für Installation und Deinstallation werden noch nicht angezeigt.
- Das Programm lädt nichts nach Intune hoch; die Werte tragen Sie anhand der erzeugten Anleitung selbst ein.

Die vollständige Liste steht in `docs/BEKANNTE-GRENZEN.md`. Prüfen Sie jedes erzeugte Paket in einer Testumgebung, bevor Sie es verteilen.
